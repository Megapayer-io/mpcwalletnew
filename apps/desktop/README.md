# MPC Wallet Desktop

Professional Web3 Desktop Wallet built with Electron and React.

## Features

- 🖥️ **Native Desktop Experience** - Custom title bar, system tray, native menus
- 🔐 **Professional Security** - PIN protection, secure key management
- 💼 **Account Management** - Create, import, and manage multiple accounts
- 🎨 **Modern UI** - Desktop-optimized interface with smooth animations
- 🔔 **Native Notifications** - Desktop notifications for transactions
- ⌨️ **Keyboard Shortcuts** - Full keyboard navigation support
- 📁 **File Integration** - Native file dialogs for wallet operations

## Development

```bash
# Install dependencies
npm install

# Start development
npm run dev

# Build for production
npm run build

# Create distributables
npm run dist
```

## Desktop-Specific Features

- **System Tray Integration** - Quick access from system tray
- **Native File Dialogs** - Import/export wallet files
- **Auto-Updater** - Seamless updates
- **Cross-Platform** - Windows, macOS, Linux support
- **Native Menus** - Professional application menus
- **Window Controls** - Custom title bar with native controls
